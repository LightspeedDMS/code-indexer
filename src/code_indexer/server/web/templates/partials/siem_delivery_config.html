SIEM Delivery (Google SecOps)

Delivers pilot security events (logins, MFA, group and permission changes, admin actions) to Google Security Operations. Capture starts only after a canary covering every mapping is accepted and confirmed visible, and every server process can mint tokens. The service-account key is pasted or uploaded below and stored encrypted in the database for every node; it is never shown again, only its identity.

Service Account Credential

Write-only. The key is validated (a service_account key whose private key loads and whose token_uri is Google's token endpoint), stored encrypted, and never returned by any page or API. The current identity is shown in the status table above.

Additional Trusted CA (optional)

CA certificates (PEM) ADDED to the default trust for the token exchange and the event import, for a TLS-inspecting proxy or a test emulator. Each must be a CA (CA=true) and unexpired. Certificate verification is always on; there is no way to skip it.

Operations
