SIEM Delivery (Google SecOps)

Delivers pilot security events (logins, MFA, group and permission changes, admin actions) to Google Security Operations. Capture starts only after a canary covering every mapping is accepted and confirmed visible, and every server process can mint tokens. The key file PATH is stored here; the key itself never leaves the file.
