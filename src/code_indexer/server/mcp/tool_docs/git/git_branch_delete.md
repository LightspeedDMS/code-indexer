---
name: git_branch_delete
category: git
required_permission: repository:admin
tl_dr: Delete a git branch (DESTRUCTIVE).
slim_description: "Delete a git branch by name (DESTRUCTIVE)."
inputSchema:
  type: object
  properties:
    repository_alias:
      type: string
      description: Repository alias
    branch_name:
      type: string
      description: Branch name to delete
    confirmation_token:
      type: string
      description: Token generated by the server. Omit it (or send an empty string) on the first call to receive a
        token, then pass that token on the second call. Tokens are single-use and expire after 5 minutes.
  required:
  - repository_alias
  - branch_name
  - confirmation_token
  additionalProperties: false
outputSchema:
  oneOf:
  - type: object
    description: Success response after deletion
    properties:
      success:
        type: boolean
        description: Operation succeeded
      deleted_branch:
        type: string
        description: Name of deleted branch
  - type: object
    description: Confirmation token response
    properties:
      requires_confirmation:
        type: boolean
        description: Confirmation required
      token:
        type: string
        description: Confirmation token to use in next call
---

TL;DR: Delete a local git branch (DESTRUCTIVE). Runs `git branch -d <branch_name>`, so git refuses to delete the current branch or a branch that is not fully merged. USE CASES: (1) Delete merged feature branch, (2) Remove obsolete branch, (3) Clean up branches.

CONFIRMATION (two calls):
1. Call with confirmation_token omitted or set to an empty string. Nothing is deleted; the response is {"success": false, "confirmation_token_required": {"token": "<6-character code>", "message": "Branch deletion requires confirmation. Call again with confirmation_token='<code>'"}}.
2. Call again with the same arguments plus confirmation_token set to that code. The branch is deleted.
Tokens are single-use and expire after 5 minutes. An invalid or expired token runs nothing; call again without a token to get a new one.

PERMISSIONS: Requires repository:admin (destructive operation).

EXAMPLE: first {"repository_alias": "my-repo", "branch_name": "old-feature", "confirmation_token": ""} returns a token such as "P9HC3V"; then {"repository_alias": "my-repo", "branch_name": "old-feature", "confirmation_token": "P9HC3V"} returns {"success": true, "deleted_branch": "old-feature"}
