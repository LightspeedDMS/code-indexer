---

inputSchema:
  type: object
  properties:

TL;DR: Remove untracked files from working tree (DESTRUCTIVE). Runs `git clean -fd`: removes untracked files and untracked directories. Ignored files are kept. USE CASES: (1) Remove build artifacts, (2) Clean untracked files, (3) Restore clean state.

CONFIRMATION (two calls):
1. Call with confirmation_token omitted or set to an empty string. Nothing is removed; the response is {"success": false, "confirmation_token_required": {"token": "<6-character code>", "message": "Git clean requires confirmation. Call again with confirmation_token='<code>'"}}.
2. Call again with confirmation_token set to that code. The clean runs and returns {"success": true, "removed_files": [...]}.
Tokens are single-use and expire after 5 minutes. An invalid or expired token runs nothing; call again without a token to get a new one.

PERMISSIONS: Requires repository:admin (destructive operation).

EXAMPLE: first {"repository_alias": "my-repo", "confirmation_token": ""} returns a token such as "R4TW8N"; then {"repository_alias": "my-repo", "confirmation_token": "R4TW8N"} returns {"success": true, "removed_files": ["build/", "notes.tmp"]}
